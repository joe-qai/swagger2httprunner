快速开始

只需几步，即可开始使用

bash 
# 克隆仓库
git clone https://github.com/joe-qai/httprunner_swagger.git

# 进入项目目录
cd httprunner_swagger

# 安装依赖
pip install -r requirements.txt

# 配置 Swagger 文档地址
# 编辑 properties/config.ini

# 运行解析器
python swaggerLib/swagger2.py

使用流程

简单五步，完成接口自动化测试

1

配置 Swagger 文档地址

编辑 properties/config.ini 文件，设置需要解析的 Swagger 接口文档地址，支持本地文件和远程 URL。

2

运行解析脚本

执行解析脚本，自动提取接口信息并生成测试数据，支持命令行参数配置输出格式。

3

选择输出格式

支持 JSON、YAML、CSV、XLSX 多种格式输出，满足不同测试框架需求。

4

导入测试框架

将生成的测试数据导入 HttpRunner 或 JMeter，执行自动化测试。

5

查看测试报告

查看测试结果报告，分析接口质量和性能指标，快速定位问题。
