HttpRunner Swagger 解析器

基于 Python 3 的接口自动化测试工具，解析 Swagger 文档，自动生成测试用例，为接口自动化测试提供完整解决方案。

核心功能

📊

Swagger 解析

支持解析 Swagger 2.x 接口文档，自动提取接口信息、参数定义和响应结构。

📤

多格式导出

支持生成 JSON、YAML、CSV、XLSX 格式的测试数据，满足不同测试框架需求。

🔌

框架集成

完美支持 HttpRunner 2.x 接口自动化测试框架，一键生成测试用例。

🚀

JMeter 支持

生成的 CSV 文件可直接用于 JMeter 数据驱动测试，无缝集成性能测试。

⚡

快速上手

简单配置即可自动生成测试用例，降低自动化测试入门门槛。

🔧

灵活配置

支持多种输出格式和定制选项，满足不同场景的测试需求。

快速开始

bash 
# 克隆仓库
git clone https://github.com/joe-qai/httprunner_swagger.git

# 进入项目目录
cd httprunner_swagger

# 安装依赖
pip install -r requirements.txt

# 配置 Swagger 文档地址
# 编辑 properties/config.ini

# 运行解析器
python swaggerLib/swagger2.py

使用流程

1

配置 Swagger 文档地址

编辑 properties/config.ini 文件，设置需要解析的 Swagger 接口文档地址。

2

运行解析脚本

执行解析脚本，自动提取接口信息并生成测试数据。

3

选择输出格式

支持 JSON、YAML、CSV、XLSX 多种格式输出，满足不同测试框架需求。

4

导入测试框架

将生成的测试数据导入 HttpRunner 或 JMeter，执行自动化测试。

5

查看测试报告

查看测试结果报告，分析接口质量和性能指标。
